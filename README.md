## О Ares Client

**Ares Client** — продвинутый utility-мод для Minecraft, ориентированный на анархию и PvP.

### Ключевые возможности:
- Мощные Combat модули
- Качественный Render (ESP, Tracers и др.)
- Продвинутые Movement модули с хорошим античит-байпасом
- Удобный ClickGUI
- Кастомизация HUD

**Поддерживаемые версии:** 1.12.2, 1.16.5, 1.17.1, 1.18.1

## Управление

- **Открыть меню**: клавиша `;` (на русской раскладке — `Ж`)
- **Префикс команд**: `-`
